# Verbal Advantage 自测网页

**纯静态单页应用**：没有后端、没有构建步骤、不联网也能用。
`docs/index.html` 是应用本体；题库拆成 `docs/data.js`（核心）+ `docs/data-levelN.js`（各级数据）。
仓库根目录的 `index.html` 只是跳转入口。

## 在线使用（GitHub Pages）

<https://sc-0571.github.io/english_learn/>

仓库已设为 public，Pages 从 `main` 分支发布。详见文末「部署」。

## 本地打开

直接双击仓库根目录的 `index.html`（或 `docs/index.html`）即可 —— 就是普通网页，不需要起服务器。

## 级别

页面顶部有「级别」下拉框，可切换 **Level 1 – Level 5**（各级 50 个 keyword）。
Level 6–10 显示为「待补」并禁用。

| 级别 | 词数 | 题数 | 结构 |
|---|---|---|---|
| Level 1 | 50 | 50 | 连线段 A=20 + 同反义 10 + 填空 10 + 辨析 10 |
| Level 2 | 50 | 50 | 同上 |
| Level 3 | 50 | **87** | **3 个连线段（A/A2/A3）共 50 题** + 同反义 15 + 填空 12 + 辨析 10 |
| Level 4 | 50 | **87** | 同 Level 3 |
| Level 5 | 50 | **87** | 同 Level 3 |

**合计 5 级、250 个词、361 道题。**

> Level 1/2 只对其中 20 个词出连线题（沿用原先的设计）；**Level 3–5 的 50 个词全部进连线段**（覆盖率 100%）。
> 连线段可以有多段（id 用 `A` / `A2` / `A3`…），每段各自用 A..T 编号。

**各级的进度、单词卡「已掌握」标记、错题本都是分开存的**，互不干扰；
切级别时会记住上次用的级别（存在 `va.curLevel`）。

## 功能

| 模块 | 说明 |
|---|---|
| **测验** | 每级 50 题：词义连线 20 + 同反义 10 + 选词填空 10 + 近义辨析 10。提交后逐题给答案与原书解析。 |
| **错题重学** | 答错**或没作答**的题自动入册；答对即移出；同一题反复错会累计次数。「重测」只出错题。可导出错题报告。 |
| **单词卡** | **一屏 2×5 共 10 张**。**正面只有英文单词**（+音标），**点一下翻面才显示中文释义**、英文释义与同反义词。翻面后可单张标「已掌握」，也可**一键把本屏 10 个全部标为已掌握**（连点即可刷完整册）。支持翻屏、全部翻面、每屏 2/4/6 行、只练未掌握、本屏批量标为未掌握。 |
| **词汇表** | 每级 50 词可搜索的速查表。 |

每次开始测验会重新打乱**选项**顺序（题目保持原书顺序，因为原书次序有难度递进）。
所有数据都存在浏览器 `localStorage`，**不会上传到任何地方**。

## 错题机制

- 提交后，答错**以及没作答**的题都会记入错题本。存储键是 `<级别>:<Part>::<裸key>`，例如 `1:A::paraphrase`。
  - **带 Part 前缀是必须的**：同一个词可能既出现在 Part A（选释义）又出现在 Part D（近义辨析），
    只用单词做键会让两条记录互相覆盖。
  - **带级别前缀**：不同级别里同名/近义的词不会串。
- **没作答 = 不会**，所以也算错题。记录里用 `skipped` 区分两者：错题页显示
  「你选了：…」是选错了，显示「**未作答**」是空着的；报告里对应「我选了: （没作答 —— 空着）」。
- 提交前若有漏答，会弹窗提醒有多少题没做，并说明**这些题会按「不会」一起记进错题本**，
  给一次机会选择「回去补完」或「就这样交卷」。未作答**不计入得分**（不会算对），但计入错题本。
- 答对一次即从错题本移除；答错则 `wrongCount++`，按错得最多的排在前面。
- **重测**只出这些错题：Part A 只保留错过的词并**重新映射选项字母**（避免靠记字母蒙对），
  Part C 的词库收窄到本题答案涉及的词。
- 「生成错题报告」输出纯文本（题目、你选的、正确答案、原书解析），可存档或贴给 AI 助手。

> 页面没有服务器，作者**看不到**你的作答。想让人/AI 帮你复盘，必须自己把报告贴出去。
> 界面上所有确认框都是页面内自绘的，不使用 `confirm()` —— 因为 `file://` 下会被浏览器静默拦截。

## 跑测试

```powershell
# 1) 数据自检：逐级检查单词表、答案合法性、matchChoices 映射、matchKey 唯一性
node docs/verify.js

# 2) 应用冒烟测试：真实加载页面，走完 Level 1/2 的判分与错题本流程
cd docs
node "C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js" install --no-save jsdom@24
cd ..
node docs/dom-test.js

# 3) 多连线段级别（3/4/5）的端到端测试：默认自动测全部，也可指定级别
node docs/test-level3.js
node docs/test-level3.js 4
```

三个脚本都以退出码 0 表示通过。`dom-test.js` 覆盖 24 组、约 200 条断言，包括：

- 四个部分全部答对 → 50/50；全部答错 → 错题本 50 条且答案文字逐条对得上
- 只做几题就交卷 → 未作答的当「不会」记入错题本（49 道空题 → 49 条记录，且 `skipped=true`）
- 未作答不计入得分（只做 1 题不会因为空着而算对）
- 错题重测 → 只出错题；答对后移出错题本
- 切换级别 → 题目换成该级的词；两级的错题本互相独立
- **单词卡网格**：一屏 10 张、**正面只有英文（不含任何中文或释义）**、逐张翻面互不影响、全部翻面、卡内单张标「已掌握」、**一键本屏全标已掌握（连点刷完 50 词并显示空状态）**、一键本屏全标未掌握（可撤销）、翻屏、每屏数量切换
- **同一个词同时出现在 A 和 D 时不互相覆盖**
- **只做 1 题 → 49 道空题进错题本、错题页显示「未作答」、重测这 49 题全对后清空**（完整闭环）
- 把原生 `confirm/alert` 换成「一调用就抛错」的函数后，所有确认流程仍正常

## 怎么扩展 Level 3–10

1. 新建 `docs/data-levelN.js`，照抄 `data-level2.js` 的结构：
   `VA.registerLevel({ level: N, words: [...50 个核心词 + 若干 extra 查询词], parts: { A, B, C, D } })`
2. 在 `docs/index.html` 里加一行 `<script src="data-levelN.js"></script>`（放在 `data.js` 之后）。
3. 跑 `node docs/verify.js` 确认没有结构错误。

页面本身不用改：下拉框会自动列出所有已注册的级别，未注册的显示「待补」并禁用。

### 数据格式要点

- `words[].zh` 的中文释义**同时**用于词汇表、单词卡和连线段的选项文字
  （`VA.matchChoices(lv, partId)` 从它生成），所以不用重复维护两处。
- **连线段可以有多段**：`parts` 里用 `A` / `A2` / `A3`… 作 key。
  每段各自用 A..T 编号（最多 26 题），`answer` 字母在该段内必须唯一。
- **Part A 的 `answer` 字母必须唯一**（每段内一一对应），
  且选项文字取自对应词的 `zh`。`verify.js` 会检查「每个字母都对得上它代表那个词的释义」——
  这条校验曾经抓到过一个隐蔽 bug：按下标另编字母会让全对的人被判成错。
- 其余段的 key 用 `B` / `C` / `D`（`B*` 是 choice、`C*` 是 bank、`D*` 是 choice）。
- 题面里出现的词（同反义词对、辨析选项）要在 `words` 里能查到释义，
  否则加 `extra: true` 补进去（这类词不计入 50 个核心词）。
